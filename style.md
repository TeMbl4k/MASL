# Дизайн-система и стиль кода

## Дизайн

Референсы владельца: тёмное спортивное приложение с оранжевыми карточками событий, выбором дня и нижним таб-баром из 5 иконок; мудборд — оранжево-красные градиенты, размытые силуэты, зерно, тонкий белый шрифт.

### Палитра

Токены Tailwind объявлены в `apps/web/src/routes/layout.css` (`@theme`). Использовать токены, а не HEX в разметке.

| Токен         | Цвет      | Назначение                                     |
| ------------- | --------- | ---------------------------------------------- |
| `brand`       | `#E85002` | Главный акцент: основные кнопки, активные чипы |
| `brand-deep`  | `#C10801` | Градиент, предупреждения                       |
| `brand-light` | `#F16001` | Градиент, наведение                            |
| `sand`        | `#D9C3AB` | Конец фирменного градиента                     |
| `ink`         | `#000000` | Фон                                            |
| `paper`       | `#F9F9F9` | Основной текст                                 |
| `gray-light`  | `#A7A7A7` | Второстепенный текст                           |
| `gray`        | `#646464` | Подписи, неактивные элементы                   |
| `gray-dark`   | `#333333` | Карточки, поля, разделители                    |

Фирменный градиент — класс `.bg-brand-glow` (чёрный → красный → оранжевый). Выделенная карточка встречи — `.bg-brand-card`: затемнённый градиент `brand` → `brand-deep`, чтобы мелкий текст `paper` держал контраст 4.5:1.

Переменные в `:root` (`layout.css`): `--safe-bottom` — нижняя безопасная зона устройства или Telegram, `--tab-bar-height` (4rem) — высота таб-бара без неё. Фокус с клавиатуры — оранжевая обводка `outline-brand` на `:focus-visible`. При `prefers-reduced-motion` анимации и переходы выключены.

### Компоненты и поведение

- Тёмная тема всегда, независимо от темы Telegram; цвета шапки и фона Mini App задаются под наш фон.
- Основная кнопка — `bg-brand`, крупный жирный текст (`text-xl font-bold`), скругление, на всю ширину внизу экрана.
- Выбранный чип — `bg-brand/20` с оранжевой рамкой; невыбранный — `bg-gray-dark`.
- Подсказки об ошибке появляются только после попытки отправить форму и исчезают, как только поле исправлено.
- Учитывать безопасные зоны Telegram (вырез, нижняя панель) и мелкие экраны от 320 px.
- Тексты по-русски, коротко, на «вы». Кнопки — глаголом: «Подать заявку», «Опубликовать».
- Касаемые элементы — не меньше 44 px (`min-h-11`, `size-11`).

### Экраны и общие компоненты (`#lib/components/`)

- **Таб-бар** (`TabBar.svelte`): фиксирован снизу, `bg-ink/90` с размытием, высота `--tab-bar-height` плюс `--safe-bottom`. Пять круглых кнопок-иконок: «Лента», «Карта», «＋», «Мои события», «Профиль». Активная — `bg-brand`, неактивная — `bg-gray-dark`; «＋» крупнее (56 px), с оранжевой рамкой. Новые заявки — точка на «Мои». На `/create` таб-бар скрыт.
- **Шапка экрана** (`PageHeader.svelte`): заголовок `text-3xl font-light`. Над ним необязательная надпись-eyebrow (`eyebrow`, мелкие прописные `text-xs tracking-[0.12em] text-gray-light`, например «Заявки»). Акцент в заголовке — сниппет `heading` со словом `font-semibold italic`: «Мои _события_», «Что _затеваем?_». Справа — действие или плашка. Своя кнопка «Назад» появляется сама, когда нет нативной кнопки Telegram.
- **Шторки** (`Sheet.svelte`): снизу, `rounded-t-3xl`, до 85% высоты, ручка сверху, заголовок `text-lg font-semibold` и крестик, фон затемнён `bg-ink/70`. Открываются только через `openSheet()` / `switchSheet()` из `#lib/tg/back.svelte.ts` (это запись истории, «Назад» закрывает шторку), фокус заперт внутри, Escape закрывает. Липкая нижняя кнопка — сниппет `footer`.
- **Плашки** (`StatusPill`, `MembershipPill`): `rounded-full px-2.5 py-1 text-xs`. Статус встречи: набор — `bg-brand/20 text-brand` (за 3 часа — обратный отсчёт жирным), мест нет и завершена — `bg-gray-dark text-gray-light`, идёт — `bg-sand/20 text-sand`, отменена — `bg-brand-deep/25`. Заявка — с рамкой: участник — оранжевая, на рассмотрении — `sand`, остальное — серая. На выделенной карточке плашки — `bg-ink/30` или белая рамка.
- **Карточки встреч** (`LobbyCard.svelte`): обычная — `rounded-3xl`, рамка `gray-dark`, фон `bg-gray-dark/40`; компактная (строки на карте и в списках) — `rounded-2xl bg-gray-dark/50`, день в начале подзаголовка, если не сегодня. **Выделенная** (`variant="featured"`) — `.bg-brand-card`, название `text-[1.375rem] font-bold`, весь текст `paper`. Выделяется первая карточка ленты, если встреча скоро и зритель проходит по карме, и ближайшая встреча хоста в «Моих». Только что созданная встреча на миг подсвечивается оранжевой обводкой.
- **Нижняя кнопка вне Telegram** (`BottomAction.svelte`) повторяет главную кнопку Telegram: на всю ширину, `rounded-2xl`, `text-xl font-bold`, над градиентом в `ink`. Неготовая форма — приглушённая, но нажимаемая.
- **Чипы и полоса дней** (`CategoryChips`, `DayStrip`): горизонтальная прокрутка без полосы, выбранный — `bg-brand/20` с оранжевой рамкой. Переключатель «Организую / Участвую» и пресеты мастера — `Segmented`.
- **Загрузка** — скелеты `animate-pulse` с фоном `gray-dark`, ошибки — `ErrorState` с кнопкой «Обновить», пустые экраны — `EmptyState` с действиями.
- **Карта:** тёмный стиль OpenFreeMap, маркеры станций с числом встреч, атрибуция OpenFreeMap и станций метро. Описание — обычным текстом (`white-space: pre-line`), без `{@html}` и автоссылок.

## Код

- Prettier (`.prettierrc`): одинарные кавычки, запятые в конце, ширина 110. `pnpm format` перед коммитом.
- Линтер — oxlint без предупреждений (`--deny-warnings`), веб проверяет `svelte-check`.
- TypeScript строгий, без `any` там, где тип известен. Данные из сети валидировать zod-схемой из `packages/shared`.
- Svelte 5: runes (`$state`, `$derived`, `$props`), состояние сессии — в `apps/web/src/lib/session.svelte.ts`.
- NestJS: модуль на ресурс (`lobbies/`, `users/`), контроллер тонкий, логика в сервисе, явный `@Inject(...)`.
- Имена: файлы `kebab-case.ts`, компоненты `PascalCase.svelte`, константы `UPPER_SNAKE_CASE`.
- Комментарии — по-английски и только там, где код сам не объясняет «почему».
- Тесты рядом с кодом (`*.spec.ts`, `*.test.ts`), интеграционные — `*.integration.test.ts`, e2e API — `apps/api/test/`.
