# Деплой на свой сервер (VPS)

Что получится: на одном сервере работают база PostgreSQL с PostGIS, приложение (API вместе с Mini App) и [Caddy](https://caddyserver.com), который сам получает HTTPS-сертификат. Адрес вида `https://203-0-113-7.sslip.io` собирается из IP сервера, покупать домен не нужно. Его вы укажете в кнопке бота.

## 0. Перед началом

**Бот.** Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, задайте имя и username (должен заканчиваться на `bot`). В ответ придёт токен вида `123456789:AA...`. Это пароль от бота: не пересылайте его никому. Если токен утёк, перевыпустите его в `/mybots` → ваш бот → API Token.

## 1. Сервер

Подойдёт любой VPS с Ubuntu 22.04 или 24.04 и 2 ГБ памяти. Пример для [Timeweb Cloud](https://timeweb.cloud) (оплата российской картой):

1. **Облачные серверы** → **Создать**.
2. Регион: **Нидерланды**. Российский регион не подходит: с марта 2026 года серверы в России не достучатся до Telegram API, а он нужен боту.
3. Образ: **Ubuntu 24.04**.
4. Конфигурация: 1–2 ядра, **2 ГБ** памяти, диск от 30 ГБ, публичный IPv4.
5. Создайте сервер. На его странице будут IP-адрес и пароль `root`.

Если у сервера включён файрвол, откройте входящие порты 22, 80 и 443.

## 2. Установка

Откройте консоль сервера: в Timeweb это кнопка **Консоль** на странице сервера, или с компьютера командой `ssh root@<IP сервера>` (в Windows в «Терминале» или PowerShell). Вставьте по очереди:

```sh
apt-get update && apt-get install -y git
git clone https://github.com/TeMbl4k/MASL.git masl
cd masl && bash deploy/install.sh
```

Скрипт поставит Docker и задаст три вопроса:

- **Домен сайта.** Нажмите Enter, чтобы взять предложенный адрес на sslip.io. Если у вас есть свой домен, направьте его A-запись на IP сервера и введите его.
- **Токен бота.** Вставьте токен от BotFather. При вводе символы не отображаются, так и должно быть.
- **Ваш Telegram ID для админки.** Число из ответа @userinfobot. С ним в профиле приложения появится раздел «Модерация». Можно пропустить и добавить позже (см. ниже).

Первая сборка идёт несколько минут. В конце скрипт напишет `Готово: https://...`. Проверка: откройте `https://<адрес>/api/health`, должно быть `{"status":"ok"}`. Сам адрес в обычном браузере покажет «Откройте приложение в Telegram»: так и должно быть, вход работает только из Telegram.

Настройки (токен, пароль базы, ключ сессий) скрипт сохранит в `masl/deploy/.env`, доступный только `root`. Миграции базы применяются сами при каждом запуске.

**Подсказки адресов (необязательно).** При создании встречи адрес может подсказывать DaData. Зарегистрируйтесь на [dadata.ru](https://dadata.ru), скопируйте API-ключ из личного кабинета, добавьте в `masl/deploy/.env` строку `DADATA_API_KEY=<ключ>` и выполните `bash deploy/update.sh`. Без ключа всё работает: место встречи выбирают точкой на карте, а адрес пишут вручную. В логах приложения при запуске видно, включены подсказки или нет.

**Админы и модераторы.** Админ разбирает жалобы и апелляции в разделе «Модерация» (профиль в приложении) и назначает модераторов из карточки пользователя. Админов задаёт строка `ADMIN_TELEGRAM_IDS` в `masl/deploy/.env`: Telegram ID через запятую, например `ADMIN_TELEGRAM_IDS=123456789`. Свой ID подскажет @userinfobot. После правки выполните `bash deploy/update.sh`. На компьютере (запуск через `docker run --env-file local.env`) добавьте ту же строку в `local.env` и перезапустите контейнер приложения.

## 3. Подключить к боту

1. @BotFather → `/mybots` → ваш бот → **Bot Settings** → **Menu Button**.
2. Отправьте адрес из шага 2, затем название кнопки, например «Открыть».
3. Откройте чат с ботом и нажмите кнопку слева от поля ввода.

По желанию: **Bot Settings** → **Configure Mini App** → **Enable Mini App** с тем же адресом. Тогда в профиле бота появится кнопка запуска и ссылка `https://t.me/<username бота>?startapp`, которой можно делиться с фокус-группой.

## 3а. Бот

Бот работает внутри приложения и сам спрашивает Telegram о новых сообщениях, отдельный адрес для него не нужен.

- **Один токен — одна копия приложения.** Если тот же токен уже работает в другом месте (например, на вашем компьютере через туннель), бот на сервере не запустится, а в логах будет «Бот не запущен: этот токен уже использует другая копия приложения». Остановите другую копию или заведите для проверок отдельного тестового бота.
- **Кнопки «Открыть заявки», «Открыть встречу» в сообщениях бота** ведут на адрес из Menu Button (шаг 3). Пока кнопка меню не настроена, бот пишет без них.
- **Чат встречи.** Хост нажимает в приложении «Создать чат встречи», и Telegram открывает выбор группы (на старых версиях Telegram бот присылает в личку кнопку выбора группы). Боту нужны права администратора «Приглашать участников» и «Блокировать участников»: Telegram предложит выдать их сам.
- **Снять блокировку создания встреч.** После отмены полной встречи меньше чем за час до начала хост теряет 30 кармы и не может создавать встречи. Хост подаёт апелляцию в профиле, модератор решает её в разделе «Модерация». Снять блокировку можно и без апелляции: «Модерация» → поиск по имени, @username или Telegram ID → карточка пользователя → «Разрешить создавать встречи».

## 4. Обновления

```sh
cd masl && bash deploy/update.sh
```

Скрипт скачает свежий код и пересоберёт приложение, база и настройки сохраняются. Если сервер ставили, пока этап 1 был в отдельной ветке, один раз переключитесь на основную: `cd masl && git checkout main && bash deploy/update.sh`.

## Полезные команды

Все команды из папки `masl`:

- Логи приложения: `docker compose -f deploy/compose.yml --env-file deploy/.env logs app --tail 100`
- Перезапуск: `docker compose -f deploy/compose.yml --env-file deploy/.env restart`
- Резервная копия базы: `docker compose -f deploy/compose.yml --env-file deploy/.env exec db pg_dump -U masl masl > backup.sql`

## Если что-то не так

- **Скрипт пишет, что сайт не ответил.** Посмотрите логи приложения и Caddy (`... logs caddy`). Если Caddy не может получить сертификат, проверьте, что порты 80 и 443 открыты.
- **Сборка падает с нехваткой памяти.** Скрипт добавляет swap на серверах меньше 3 ГБ; если сборка всё равно падает, возьмите сервер с 2 ГБ памяти или больше.
- **Не скачиваются образы Docker.** Если Docker Hub недоступен, скрипт сам подключает зеркала (Timeweb и Google). Если зеркала уже настроены по-другому, проверьте `/etc/docker/daemon.json`.
- **«Не удалось подтвердить вход через Telegram».** Токен в `deploy/.env` от другого бота. Исправьте `BOT_TOKEN` в этом файле и выполните `bash deploy/update.sh`.
- **Не открывается из России.** Telegram с весны 2026 года без VPN почти недоступен, зарубежные серверы тоже могут открываться не у всех провайдеров. Проверяйте с VPN.
- **Отладка в Telegram Desktop:** Settings → Advanced → Experimental settings → Enable webview inspecting, затем правый клик в Mini App → Inspect.
