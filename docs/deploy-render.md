# Бесплатный деплой: Render + Neon

Что получится: база PostgreSQL с PostGIS в [Neon](https://neon.com) и приложение (API вместе с Mini App) в [Render](https://render.com) по адресу `https://<имя>.onrender.com`, который открывается кнопкой в вашем боте. Оба сервиса бесплатны и не просят карту. Интерфейсы на английском, ниже названия кнопок как в них.

Ограничения бесплатных тарифов:

- Render усыпляет приложение после 15 минут без запросов. Первое открытие после этого занимает около минуты, пока оно просыпается. Для показа фокус-группе откройте приложение заранее.
- Render даёт 750 часов работы в месяц, одному сервису этого хватает на весь месяц.
- Neon даёт 0,5 ГБ на базу, для MVP этого достаточно. Свою бесплатную базу Render не используем: она удаляется через 30 дней.

## 0. Перед началом

**Бот.** Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, задайте имя и username (должен заканчиваться на `bot`). В ответ придёт токен вида `123456789:AA...`. Это пароль от бота: не пересылайте его никому. Если токен утёк, перевыпустите его в `/mybots` → ваш бот → API Token.

**Случайная строка** для `JWT_SECRET`, 32+ символа: генератор паролей (только буквы и цифры) или команда `openssl rand -hex 32`.

## 1. База в Neon

1. Зайдите на [console.neon.tech](https://console.neon.tech) через GitHub или Google.
2. Создайте проект: любое имя, регион **AWS Europe Central 1 (Frankfurt)**, версия Postgres по умолчанию.
3. На главной странице проекта нажмите **Connect**.
4. Выключите переключатель **Connection pooling**. Это важно: миграции берут блокировку, которая через пул соединений не работает.
5. Скопируйте строку подключения. Она начинается с `postgresql://` и заканчивается на `?sslmode=require` (иногда ещё `&channel_binding=require`, это не мешает). Адрес хоста не должен содержать `-pooler`.

Расширение PostGIS приложение включит само при первом запуске.

## 2. Приложение в Render

1. Зайдите на [dashboard.render.com](https://dashboard.render.com) через **GitHub**.
2. **+ New** → **Web Service** → **Git Provider** → разрешите доступ к репозиторию `TeMbl4k/masl` → выберите его.
3. Заполните форму:
   - Name: например `masl`, из него получится адрес.
   - Language: **Docker** (Render определит сам по `Dockerfile`).
   - Branch: `main`.
   - Region: **Frankfurt**, рядом с базой.
   - Root Directory оставьте пустым.
   - Instance Type: **Free**.
4. **Environment Variables** → **Add from .env**, вставьте и подставьте свои значения:

   ```
   NODE_ENV=production
   DATABASE_URL=<строка подключения из Neon>
   BOT_TOKEN=<токен от BotFather>
   JWT_SECRET=<случайная строка>
   ```

5. **Advanced** → **Health Check Path**: `/api/health`.
6. **Deploy Web Service**. Первая сборка идёт несколько минут, ход виден в логах на той же странице.

Проверка: откройте `https://<имя>.onrender.com/api/health`, должно быть `{"status":"ok"}`. Сам адрес в обычном браузере покажет «Откройте приложение в Telegram»: так и должно быть, вход работает только из Telegram.

Миграции базы применяются сами при каждом запуске.

## 3. Подключить к боту

1. @BotFather → `/mybots` → ваш бот → **Bot Settings** → **Menu Button**.
2. Отправьте адрес `https://<имя>.onrender.com`, затем название кнопки, например «Открыть».
3. Откройте чат с ботом и нажмите кнопку слева от поля ввода.

По желанию: **Bot Settings** → **Configure Mini App** → **Enable Mini App** с тем же адресом. Тогда в профиле бота появится кнопка запуска и ссылка `https://t.me/<username бота>?startapp`, которой можно делиться с фокус-группой.

## 4. Обновления

Каждый push в `main` Render деплоит сам.

## Если что-то не так

- **Деплой упал.** Откройте сервис → **Logs** (или **Events** → нужный деплой). Если ошибка на сборке, проверьте ветку. Если после запуска, сообщение «Некорректные переменные окружения» перечисляет, какую переменную поправить.
- **«База пока недоступна» до последней попытки или ошибка подключения.** Проверьте `DATABASE_URL`: строка целиком из Neon, с `?sslmode=require`, без `-pooler` в адресе.
- **«Не удалось подтвердить вход через Telegram».** `BOT_TOKEN` в Render от другого бота, не от того, из которого открыто приложение.
- **Mini App долго грузится.** Приложение просыпалось после простоя, подождите около минуты.
- **Не открывается из России.** Telegram с весны 2026 года без VPN почти недоступен, зарубежные хостинги тоже могут открываться не у всех провайдеров. Проверяйте с VPN.
- **Отладка в Telegram Desktop:** Settings → Advanced → Experimental settings → Enable webview inspecting, затем правый клик в Mini App → Inspect.
